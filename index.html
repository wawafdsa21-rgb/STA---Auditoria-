Como configurar (uma vez)
  1. Abra a planilha Auditoria (Google Sheets).
  2. Extensões → Apps Script. Apague o conteúdo e cole o código do arquivo apps_script_auditoria.gs.
  3. Implantar → Nova implantação → tipo App da Web. Executar como: Eu. Quem pode acessar: Qualquer pessoa. Autorize.
  4. Copie o URL do app da Web (termina em /exec), cole acima e toque em Salvar endereço.

Atenção: aberto pelo link do Claude, o navegador bloqueia o envio para o Google. Use o arquivo HTML aberto no navegador do celular para enviar à planilha.
